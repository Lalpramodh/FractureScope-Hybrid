FractureScope model contract

YOLOv8 remains the only local inference model. Keep yolov8_model.pt in the project root or set YOLO_MODEL_PATH. Each Gunicorn worker lazily loads one detector, reuses it for CPU inference, and never unloads it between requests.

Render inference uses a single resized image at imgsz=320, torch.inference_mode(), confidence 0.25, and max_det=10. Model fusion and startup warmup are intentionally disabled to reduce peak memory. The health endpoint does not load YOLO.

Groq Vision is the secondary analysis system. The application sends padded crops for at most GROQ_MAX_REGIONS regions per upload, defaulting to the three highest-confidence YOLO detections. GROQ_API_KEY is read only from the environment and GROQ_VISION_MODEL is configurable.

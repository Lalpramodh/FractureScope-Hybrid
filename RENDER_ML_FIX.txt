FractureScope Render deployment notes

- Production uses yolov8_model.onnx, exported from the unchanged yolov8_model.pt source model.
- The ONNX session is lazy-loaded once per Gunicorn worker and reused; /health does not load it.
- CPU inference uses OpenCV-compatible rectangular stride-aligned letterbox preprocessing, target size 320, confidence 0.25, IoU 0.45, and max_det 10.
- The runtime has one sequential ONNX CPU thread configuration and no model warmup.
- Gunicorn runs one worker and one thread: gunicorn app:app --workers 1 --threads 1 --timeout 300
- PostgreSQL is used when DATABASE_URL is set; SQLite is a local-development fallback.
- Tables are created with CREATE TABLE IF NOT EXISTS and existing records are preserved.
- Set SECRET_KEY and DATABASE_URL in Render.

FractureScope Render deployment notes

- The application uses yolov8_model.pt as its only local inference model.
- The detector is lazy-loaded once per Gunicorn worker and reused; /health does not load it.
- CPU inference uses a single 320px inference image, torch.inference_mode(), confidence 0.25, and max_det 10.
- Model fusion and startup warmup are disabled to avoid load-time memory spikes.
- Gunicorn runs one worker and one thread: gunicorn app:app --workers 1 --threads 1 --timeout 300
- Groq Vision analyzes at most three highest-confidence detection crops by default.
- PostgreSQL is used when DATABASE_URL is set; SQLite is a local-development fallback.
- Tables are created with CREATE TABLE IF NOT EXISTS and existing records are preserved.
- Set SECRET_KEY, DATABASE_URL, and GROQ_API_KEY in Render. GROQ_VISION_MODEL is configurable.
